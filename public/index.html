FaWave(发微)

经典且持续维护的多平台分享扩展

面向 Chromium 浏览器，支持将网页、选中文本、链接、图片等内容快速分享到多个已授权账号， 同时保留多账号管理、快捷发送、URL 缩短与 AI 总结等能力。

核心能力

把“看到内容就发出去”这件事做得更顺手

多入口分享

支持弹出页发送，也支持在网页右键菜单中直接使用 `Share with FaWave` 调起快捷发送面板。

多类型内容

支持当前网页、选中文本、链接和图片分享，适合转帖、摘录、同步评论和素材搬运。

多账号管理

可管理多个已授权账号，支持默认发送策略、快捷发送与按需同步到多个平台。

AI 总结网页

可为当前网页生成适合直接分享的简短摘要，并提供模型、Base URL、API Key 等配置入口。

辅助工具

保留 URL 缩短、图片上传、截图分享等能力，减少从阅读到发帖之间的切换成本。

持续维护

当前项目已补充基础单元测试、mock 测试和首批 E2E 基础设施，便于继续维护和迭代。

安装方式

支持商店安装，也支持本地加载

浏览器商店安装

适合普通用户，安装后即可直接使用。

Chrome Web Store

本地加载开发版

  1. 打开 `chrome://extensions/` 或 `edge://extensions/`
  2. 开启“开发者模式”
  3. 选择“加载已解压的扩展程序”
  4. 指向本地 `fawave` 项目目录

FAQ

一些常见问题

FaWave 现在还是老插件吗？

不是简单存档版。当前代码已经适配 Manifest V3，并保留兼容层，让经典功能在现代浏览器环境下继续可用。

为什么支持的平台没有以前那么多？

官网以当前代码仓库中的真实可维护能力为准，只展示仍有接入实现和维护价值的平台。

AI 总结默认可用吗？

需要先在扩展的高级设置中配置 AI 提供方、模型、接口地址和 API Key，之后才能在网页上调用总结功能。

Twitter / X 为什么需要自己提供 Key？

当前接入方式依赖用户自己的开发者凭据，这是为了适配现有接口政策并保证可持续使用。
